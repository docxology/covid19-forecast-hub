# COVID-19 Forecast Hub

This Docxology fork retains published aggregate forecasts from the CDC
COVID-19 Forecast Hub. Forecasts cover weekly hospital admissions and,
where submitted, the proportion of emergency department visits attributed
to COVID-19.
